Data Structures – List, Dictionary, Set & Conditional Statements

About This Assignment

In this assignment, I practised using list creation, list operation/modifications, accessing list elements, dictionaries (creation, modification and access), sets (operations), and operators & conditional statements (if, elif, else) statements to check conditions in Python. 
1.	List Creation

•	Created age_list and name_list with five integer and string elements.

2.	List Operations /Modifications

•	Added and removed elements from lists.
•	Used append (), insert (), remove (), pop (), and extend ().
•	Sorted the age list in descending order.
•	Found the maximum age, minimum age, and sum of all ages.

3.	Accessing List Elements

•	Accessed list elements using indexing and slicing.
•	Reversed the list elements.

4.	Dictionary Operations

•	Created a dictionary named student_marks with student names and marks.
•	Accessed the marks of a particular student.
•	Added a new student named “Janani” with a mark of 80.
•	Updated an existing student's mark to 82.
•	Used keys (), values (), and items () to display dictionary data.

5.	Set Operations

•	Created a set using vowel values, including duplicate elements. The value shows error because the SET is mutable, that we can add and delete elements but can change the elements from the set, it doesn’t have index number since it is unordered values. 
•	Observed how sets handle duplicate values.
•	Checked whether set elements can be modified using indexing.
•	Created two sets and performed union and intersection operations.

6.	Conditional Statements

•	Used if, elif, and else statements to classify a performance score.
•	Accepted a score from the user between 0 and 10.
•	Displayed the performance category based on the entered score.
•	Added a feedback message for each performance category.


Conclusion

Through this assignment, I gained a better understanding of Python data structures and their basic operations. I also learned that sets store unique values and do not support indexing. The conditional statement exercise helped me understand how to check conditions and display the appropriate output. Language used is Python.
This assignment helped me practise the basic concepts of Python through simple programs. I will continue practising these concepts to improve my programming skills.
